# Machine Learning & AI Internship - Week 1

## Titanic Survival Prediction - Data Cleaning Project

### Objective

The objective of this project is to perform data exploration and preprocessing on the Titanic dataset.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

### Tasks Completed

- Loaded and explored the Titanic dataset
- Generated dataset statistics using info() and describe()
- Identified missing values
- Handled missing values using median/mode imputation
- Encoded Sex using LabelEncoder
- Encoded Embarked using OneHotEncoder
- Visualized age distribution
- Exported the cleaned dataset
- Performed train/test split

### Files

- Week_1_Titanic_Data_Cleaning.ipynb - Complete notebook
- titanic_cleaned.csv - Cleaned dataset
- age_distribution.png - Age distribution visualization

### Conclusion

The Titanic dataset was successfully cleaned and transformed into a format suitable for further machine learning tasks.
